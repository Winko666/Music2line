# Music2line

中文 · [English](README.md)

Music2line 是为小爱音箱设计的独立桌面歌词屏。你像平常一样说「小爱同学，播放周杰伦的《晴天》」，音箱负责播放，旁边的歌词屏负责听出歌名、查找带时间戳的歌词，并随着实际唱到的位置逐行高亮。设备计划使用 **RT-Thread Titan Board Mini**，接电、联网后独立运行。

**项目进度**　目前处于硬件设计阶段。仓库中的 BetterLyrics 桌面端源码用于参考歌词搜索、解析和显示逻辑。Titan Mini 固件、在线服务接入和真机同步测试均待完成。

## 歌词怎样跟上音箱

1. **点歌时预查歌词。** 板载麦克风采集点歌指令，通过联网语音转写提取歌名和歌手，搜索带逐行时间戳的歌词（如 LRC）。
2. **开唱后确认版本。** 设备从音箱实际播出的音乐中采集短片段。识曲服务需要返回曲目和片段在录音中的位置，以便区分同名歌曲、录音室版和现场版，并选取对应歌词。
3. **播放中持续校准。** 两次识别之间，用板上的时钟推进歌词。收到新的可靠匹配时，按片段采集时刻换算当前进度，补偿网络往返耗时。小偏差逐步修正，暂停恢复后重新定位，确认切歌后重新查词。若歌词文件本身标错时间，则需要更换或修正该文件。

## 首版硬件清单

| 部件 | 数量 | 用途 |
| --- | --- | --- |
| 小爱音箱 | 1 台 | 沿用现有音箱，负责语音唤醒和音乐播放。 |
| RT-Thread Titan Board Mini（瑞萨 RA8P1） | 1 块 | 运行 RT-Thread，用板载 PDM 麦克风采集人声和音乐，用 LVGL 显示歌词。 |
| Mini 版兼容的 RGB565 液晶屏及配套排线 | 1 套 | 桌面近距离阅读可选 4.3 英寸。购买前核对 Mini 版引脚、屏幕时序和配套转接板。 |
| ESP32-C3 串口 Wi-Fi 模块 | 1 块 | 无线方案拟用带天线、运行 ESP-AT 固件的模块，通过 UART 接入 Titan Mini，为识曲和查词联网。 |
| 5 V USB 电源及 USB-C 线 | 1 套 | 为设备供电，电流容量按主板和所选屏幕的总功耗确定。 |

如使用有线网络，可将 Wi-Fi 模块换成 Mini 版配套的 FPC 转 RJ45 配件和网线。开发阶段可使用支持 RA8P1 的 J-Link 通过 SWD 烧录和调试。[Titan Mini 官方板级支持包](https://github.com/RT-Thread-Studio/sdk-bsp-ra8p1-titan-mini) · [乐鑫 ESP-AT 文档](https://docs.espressif.com/projects/esp-at/zh_CN/latest/esp32c3/Get_Started/What_is_ESP-AT.html)

## 原型验证

首轮测试计划用同一首歌的录音室版和现场版，检查屏幕选中的歌词版本及首句出现的时刻。随后测试暂停、继续和中途切歌，记录重新对齐所需的时间。语音转写服务、能返回播放位置的识曲服务和带时间戳的歌词来源仍待选定。
